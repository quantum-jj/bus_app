# Bus Checker

A minimalist bus tracker app to see when the next bus on your favourite route arrives.

Built as a PWA (Progressive Web App) — installable on iOS and Android for a native app feel. Dark, iOS-style UI with no dependencies.

## Features
- Track arrival times for your favourite bus routes
- Installable as a home screen app on mobile
- Fully offline-capable after first load

## Usage

Open `index.html` in a browser, or visit the hosted version at:
`https://quantum-jj.github.io/bus_app`

## Tech
Plain HTML, CSS, and JavaScript — no frameworks, no build step required.
